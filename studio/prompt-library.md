# Prompt library

Copy, fill the `<placeholders>`, paste. Every prompt runs inside this project, so the studio rules,
skills and brand memory apply automatically. Add the phrase **"go all out"** as an effort multiplier.

---

### 1. One-liner showreel (tests the harness)
> Make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are. Like it's your showreel for a résumé. Go all out.

### 2. Brand launch film from a URL (researches assets itself)
> Make a 15-second motion graphics launch video for **<Brand>** (<url>). <One or two sentences on what's new>. Gather the brand assets yourself: use actual product screenshots, the real logo, real colors and fonts. 16x9 and 9x16. Go all out.

### 3. Steal the grammar of a reference
> Here is a reference: <x.com / youtube url>. Download it, extract a frame every 0.5s, and write a style guide covering palette, type, shot lengths, transition types, camera moves, texture/grain, and how text enters and exits. Then write a shot list for a 15-second launch video about **<Brand>** in that style, using real screenshots. Take the grammar of the reference, never its content, logos or characters.

### 4. One-container product UI film (show me the beat grid first)
> Product: <what it is>. Assets: brands/<slug>/. Direction: product film, UI motion — one container never cuts; every state is the same element changing size, radius and fill while its content swaps behind a short blur. Structure: <state 1 → state 2 → … → logo>. Gotchas: <anything to avoid>. Show me the state list on the beat grid before writing code.

### 5. Score it to the beat
> Score the <project> film to the beat. Synthesize an original 120 BPM track in code on the same timeline as the picture. Output beats.json with BPM, beats, downbeats and hits. Synthesize UI sounds: a click on every cursor press, a whoosh on every container morph, a thump on the logo. Then retime the animation to beats.json.

### 6. Voice-over with Fish Audio
> Use Fish Audio to write and generate a voice-over for <project>: <tone>, <language>, voice <name / "find a warm confident English voice" / my cloned voice>. Add delivery tags where they help ([excited], [calm]). Time the picture to the measured line durations and duck the music under it.

### 7. The director's brief (long-form, highest quality)
> You are the director, animator, sound designer and render engineer for **<film name>**, made in code. Film in one line: <…>. References: <…>. Tools & keys: <Fish Audio voice / music style / assets>. Characters: <…>. Beat sheet: <…>. Text on screen: <verbatim>. Gates: show me the brief, then the beat grid, then style frames before the full render. Critique loop until every axis ≥ 8. Deliverables: <formats, duration>.

### 8. Critique loop on an existing render
> Critique round on <project>: grab stills every 0.5s, score it on the 9 axes in templates/critique.md, fix the lowest scores, re-render, and repeat until everything is 8+. Show me the scores each round.

### 9. Ad set
> Make a 6s, 15s and 30s ad for **<Brand>**'s <product/feature> for <platform>. One message: <message>. CTA: <cta>. Formats 9x16, 1x1, 4x5. Hook must work in the first frame with sound off.

### 10. Product walkthrough
> Make a 45-second walkthrough of how to <task> in **<Product>** (<url>). Recreate the real UI, use a cursor for every action, zoom the camera to each step, number the steps, and add a Fish Audio voice-over that explains each step in plain language.

### 11. Package a repeatable format
> Package what we just did as a skill called <name>: it should ask me for the URL, duration and formats, then run this exact pipeline with these hard rules: <rules>.
